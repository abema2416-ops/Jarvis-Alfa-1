# Джарвис-1 Альфа

Офлайн-помощник для Android: запускает модели в формате GGUF прямо на телефоне (движок llama.cpp), без интернета.

- Готовое приложение: раздел **Releases** → `Jarvis.apk`.
- Модели (.gguf) кладутся в папку `Jarvis/models` во внутренней памяти телефона.
- Сборка идёт автоматически на вкладке **Actions** после каждого изменения.
